# Hypermark

A calm, responsive to-do planner for turning small goals into steady progress.

## Features

- Add goals with priority and due dates
- Mark goals complete or reopen them
- Delete goals
- Search and sort your goals
- Filter by all goals, today, upcoming, or completed
- Track completion progress
- Automatically save goals in your browser with local storage
- Responsive layout for desktop and mobile

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Publish With GitHub Pages

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Click **Save**.

GitHub will provide a public link to your Hypermark app.

## Project Structure

- `index.html` - Page structure
- `style.css` - Responsive styling
- `script.js` - Goal management and local storage logic
